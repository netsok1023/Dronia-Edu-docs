3
따라 입력 · Cowork 1차 브리핑
입력 도구 · Cowork
오늘의 '증시 브리핑'을 한 장으로 정리해줘. (웹에서 최신 정보를 검색해서)
- '표' 두 개로 정리해줘: ① 미국 3대 지수(S&P500·나스닥·다우) ② 한국(코스피·코스닥). 각 표 컬럼 = 지수 · 종가 · 등락(%).
   (용어는 '종가'로 통일하고, 각 표 머리에 '기준 거래일'을 표시 — 국내 전일, 미국 그 전 거래일.)
- 표 아래 '시장을 움직인 핵심 이슈' 2~3개(사실 위주, 출처 링크).
- 각 수치마다 어느 거래일 기준·출처를 함께. 확실치 않으면 지어내지 말고 '확인 필요'로.
- ※ 투자 권유·전망(오른다/사라)은 빼고 '사실 정리'만 해줘.
빠진 정보 있으면 작업 전에 나에게 먼저 물어봐서 꼼꼼히 확인 후 진행해줘.
원칙종가·지수는 시점이 생명 — 링크 받아 직접 확인, 투자 권유는 다루지 않습니다.

입력 도구 · Cowork

각 항목은 아래 '지정 출처'를 열어(웹 읽기) 값을 가져오고, 값마다 출처·기준일을 표시해. 정말 못 찾으면 '확인 필요 + 그 출처 링크'로.
- 지수(종가·등락·장중 고저·최근 5일): 네이버 금융 / Investing.com / Yahoo Finance 각 지수 페이지에서.
- 한국 수급·업종: 네이버 금융 '투자자별 매매동향' 또는 KRX.
- 미국 섹터·대표 종목 등락: Yahoo Finance / Finviz(섹터·등락 상위).
- 거시(원/달러·미 10년 국채금리·WTI·금): Investing.com 각 지표 페이지.
- 다가오는 일정: Investing.com 경제캘린더.
- 시장 이슈 4~5개: 주요 매체 기사 + 링크.
맥락의 힘"더 자세히" 대신 구체적 항목으로 쪼개면 결과가 완전히 달라집니다.

1
준비물 세부 · myaccount.google.com

Gmail 앱 비밀번호

브리핑이 도착할 '메일'입니다. 프로그램이 내 Gmail로 메일을 보내려면 로그인 비밀번호가 아니라 '프로그램 전용' 16자리 앱 비밀번호가 필요합니다.
  1. Gmail 계정 준비없으면 gmail.com에서 생성 — 이 주소로 나에게 보내고 나에게 받습니다(자기 메일로 발송).
  2. 2단계 인증 켜기myaccount.google.com → 보안 → 2단계 인증. (앱 비밀번호를 만들려면 꼭 필요)
  3. 앱 비밀번호 만들기myaccount.google.com/apppasswords → 앱 이름(예: brief) 입력 → 만들기 → 16자리 복사.
주의이 16자리는 비밀번호처럼 — Claude·코드에 직접 적지 않기(자동화 때 강사가 GitHub Secrets에 입력). 화면·메뉴는 바뀔 수 있어 강의 직전 확인.
2
준비물 세부 · openrouter.ai/keys

무료 LLM 키

종목 '한 줄' 코멘트와 시장 이슈 '글'을 만드는 AI에 접속하는 열쇠입니다. 결제수단 없이 무료 모델로 시작할 수 있어요.
  1. OpenRouter 로그인openrouter.ai → 우상단 Sign In → Google 계정으로 로그인(가장 간단).
  2. 키 만들기openrouter.ai/keys → Create Key → 이름 아무거나 → 생성.
  3. 키 복사표시된 sk-or-…를 복사(이 화면에서만 보임) → 안전하게 보관.
주의이 키는 비밀번호처럼 — Claude·코드에 직접 적지 않기(강사가 GitHub Secrets에). 무료 한도·화면은 바뀔 수 있어 강의 직전 확인.
3
준비물 세부 · github.com/new

GitHub 빈 저장소

매일 도는 프로그램이 '살 집'입니다. 코드를 보관하고, 매일 자동으로 실행되는 곳(자동 실행소)이에요.
  1. GitHub 가입github.com 가입(이메일·비밀번호·사용자명, 이메일 인증).
  2. 새 저장소 만들기우상단 ＋ → New repository → 이름(예: my-market-brief) → Public → Create repository.
  3. 주소 복사만들어진 저장소 주소(URL)를 복사 → Claude Code에 알려줍니다.
참고여긴 비밀값이 없습니다 — Public이어도 안전(키는 GitHub Secrets에 따로). 화면·메뉴는 바뀔 수 있어 강의 직전 확인.

function sendAutomatedMarketBriefing() {
  var recipient = "본인메일주소@gmail.com";   // ← 여기만 내 메일로!

  var today = new Date();
  var dateString = Utilities.formatDate(today, "Asia/Seoul", "yyyy년 MM월 dd일");
  var subject = "📊 오늘의 증시 브리핑 (" + dateString + ")";

  // ── 시세: 야후 파이낸스 차트 API 직접 호출(yfinance 대체) ──
  function getStockData(ticker) {
    var url = "https://query1.finance.yahoo.com/v8/finance/chart/" + encodeURIComponent(ticker) + "?range=5d&interval=1d";
    var options = { muteHttpExceptions: true, headers: { "User-Agent": "Mozilla/5.0" } };
    try {
      var data = JSON.parse(UrlFetchApp.fetch(url, options).getContentText());
      if (!data.chart || !data.chart.result) return { close: "확인 필요", change: "0.00" };
      var closes = data.chart.result[0].indicators.quote[0].close.filter(function(v){ return v !== null; });
      var latest = closes[closes.length - 1], prev = closes[closes.length - 2];
      var pct = ((latest - prev) / prev) * 100;
      var isKr = ticker.indexOf(".KS") !== -1 || ticker.indexOf(".KQ") !== -1 || ticker.indexOf("^KS") !== -1 || ticker.indexOf("^KQ") !== -1;
      var close = isKr ? Math.round(latest).toLocaleString('ko-KR') : latest.toLocaleString('en-US', {minimumFractionDigits:2, maximumFractionDigits:2});
      return { close: close, change: pct.toFixed(2) };
    } catch(e) { return { close: "오류", change: "0.00" }; }
  }
