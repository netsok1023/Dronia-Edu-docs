완성합니다.

연락처 QR + 예쁜 명함 이미지 — 파일 하나, 계정 하나 없이도 됩니다.
STEP 1 도입

오늘은 — '나' 자신을 만듭니다. 바로 내 명함을요.
🪧 종이 명함은 버려져도, QR 명함은 폰에 저장됩니다.
STEP 2 되네! · 🟢
제일 먼저 — 스캔하면 내 연락처가 저장되는 QR부터. 이게 '디지털 명함'의 심장이에요.
그리고 명함의 진짜 비결 하나 — '무엇을 앞세우느냐(위계)'예요. AI는 시키는 대로 키우니까, 크게 보일 것·작게 둘 것을 내가 직접 정해서 알려줘야 합니다.
준비 — 시작 전 빈 폴더 하나(예: 바탕화면 '내명함') + 파일은 'card.html' 하나로 키운다(새 파일 X, 항상 이어서).

핵심 팁QR이 실제로 스캔되는 코드로 생성됐는지 확인 — 빈 네모면 라이브러리로 다시 요청.

AI는 시키는 대로 키우니 — 크게 보일 것·작게 둘 것을 정해 알려줘야 합니다. 참고 이미지를 줄 땐 "디자인 느낌만, 글자 배치는 내 지시 우선"이라고 말하기.

+
폰
모바일 우선인 이유

결국, 폰에서 봅니다

디지털 명함은 카톡·문자로 받고 폰으로 엽니다. '모바일 우선'을 꼭 넣어야 PC에선 멀쩡한데 폰에선 글자·버튼이 깨지는 일이 없습니다.

강사 시연 예 — '(주)드로니아 대표·AI·바이브코딩 교육'을 앞세우고, 드론농구·협회장은 작은 부가 한 줄로(앞세울 것을 바꾸면 같은 명함도 완전히 달라집니다).
STEP 2 확인

'오, 저장되네!' — 첫 성공

확인 순서
  1. 브라우저로 열어 QR이 실제로 떴는지 먼저 확인
  2. 폰 카메라로 스캔
  3. 연락처 저장 화면이 뜨는지 확인
빈 네모로 나오면(트러블슈팅)
  1. "QR 생성 라이브러리로 진짜 스캔되는 QR을 그려줘"라고 재요청
  2. 그래도 안 되면 무료 QR 생성기 사이트에 vCard 정보를 넣어 PNG 다운로드
  3. 폰마다 스캔 동작이 달라 강의 직전 1회 실기 확인(아이폰/안드로이드)
"오, 내 연락처가 저장되네!" — 이게 첫 성공이에요.

이왕이면 예쁜 명함이면 좋겠다."
그쵸? 바로 그때가 다음 단계예요.
STEP 4 와~! · 🟢
이제 '한 장의 예쁜 명함'으로 만듭니다.
인쇄해도 되고, 카톡으로 보내도 되는.
STEP 4따라 입력 · Cowork
① 명함 디자인
입력 도구 · Cowork
이어서, 이 디지털 명함을 '예쁜 명함 카드'처럼 디자인해줘. (기존 정보·QR 유지)
- 한 장의 명함 레이아웃: 한쪽에 이름·직함·한 줄 소개·연락처, 다른 한쪽에 QR.
- 신뢰감 있는 느낌(넉넉한 여백, 또렷한 글씨, 색 1~2가지로 절제).
- 로고가 있으면 넣어줘(없으면 이름 이니셜로 심볼).
[하지 말 것] 과한 장식 금지, 글씨가 QR을 가리지 않게, 단일 HTML·반응형 유지.
디자인여백은 넉넉하게, 색은 1~2가지로 절제 — 신뢰감의 비결.
STEP 4따라 입력 · Cowork
② 이미지로 저장(자랑하기)
입력 도구 · Cowork
이어서, 이 명함을 '이미지 파일'로 저장하는 '명함 저장' 버튼을 넣어줘.
- 명함을 코드로 그려서(canvas) PNG 이미지로 생성. ★QR코드도 반드시 이미지 안에 함께 들어가게(QR은 외부 이미지 말고 파일 안에서 생성, 저장 직전 'QR이 다 그려진 뒤'에 캡처).
- 저장 방식은 기기에 맞게: PC = 바로 다운로드(다운로드 폴더) / 휴대폰 = 공유 시트(사진 저장·카톡 전송).
- 저장이 끝나면 '저장했어요 — 다운로드 폴더 확인' 안내를 잠깐 띄워줘.
[하지 말 것] 윈도우 '공유'창엔 폴더 저장이 없으니 PC는 반드시 다운로드 방식으로, 단일 HTML 유지.
자주 나는 버그저장한 이미지에 QR이 빈자리로 나오면 = 이미지 굽는 코드가 QR을 안 담은 것 → "이미지에 QR도 반드시 포함, QR은 파일 안에서 생성"이라고 콕 집어 다시 요청.

③ 한국어 / English 전환 · 글로벌 지금은 글로벌 시대니까요
입력 도구 · Cowork
이어서, 이 명함에 '한국어 / English' 전환 버튼을 넣어줘.
- 버튼을 누르면 이름·직함·소개·연락처가 국문/영문으로 바뀌게(같은 한 페이지 안에서).
- 영문은 내 정보를 번역: 이름은 로마자, 직함·회사는 영문.
- ★전환에 '연동'되게: '명함 저장(이미지)'은 지금 보이는 언어 그대로 저장 / QR도 그 언어 vCard로 '다시 생성'(국문=한글 / 영문=로마자).
- 디자인·레이아웃·모바일 우선은 그대로, 단일 HTML 유지.
[확인] 이름 로마자·회사 공식 영문명·직함 번역은 내가 검수해 고칠 수 있게.
교육 포인트저장 이미지는 언어 그대로 자동 따라옴. QR은 데이터라 자동 안 바뀜 → "그 언어 vCard로 재생성"을 콕 집어야. 번역은 초안 — 로마자·영문명은 본인 검수.

PART 02 · 심화

명함을,
폰 앱으로.

배포(https) → 폰 홈 화면에 설치. 시간 되면 이어가고, 못 하면 강사 시연으로 봅니다.
STEP 5 심화(여유 되면) · 🟡
마지막 욕심 — 명함을 폰 홈 화면에 앱 아이콘으로 깔아두는 거예요.
누가 명함 달라 하면, 아이콘 탭 한 번에 전체화면 명함이 뜹니다. 종이 명함은 이제 안녕입니다. 딱 하나 알아둘 것 — 이게 되려면 명함이 인터넷 주소(https)에 올라가 있어야 해요(파일 더블클릭으론 안 됨).
그래서 5차시에서 배운 GitHub Pages로 먼저 올리고, 그다음 '홈 화면에 추가'합니다. 배포는 따로 노는 게 아니라, 앱으로 깔기 위한 준비입니다.
STEP 5 심화 지도

네 조각만 이으면, 폰 앱처럼

① 배포 · GitHub Pages
https 주소로 — 파일명은 index.html
② 앱 설정 · manifest+아이콘
이름·테마색·아이콘·iOS 메타
③ 업로드 · 저장소에 반영
새 파일들을 GitHub에 올리기
④ 홈 화면 추가 · 아이콘 탭
주소창 없이 전체화면 명함
5차시에서 배운 GitHub Pages 그대로 — 배포는 따로 노는 게 아니라, 앱으로 깔기 위한 준비입니다.
준비 — 1회만
깃허브는 계정·로그인(1회)만 사람이 해주면 됩니다.
5차시에서 해뒀으면 그대로 재사용, 처음이면 가입·로그인부터. 로그인만 돼 있으면 다음 프롬프트는 Claude Code가 저장소 생성 → 업로드 → Pages 설정까지 알아서 하고, 강사·교육생은 주소만 받습니다.
STEP 5따라 입력 · Cowork/Claude Code
① 인터넷에 올리기(배포) 5차시 'GitHub Pages' 방식 그대로
입력 도구 · Cowork/Claude Code
지금 만든 디지털 명함(card.html)을 GitHub Pages에 올려서 인터넷 주소(https)로 열리게 해줘. 단, 올릴 때 파일 이름은 'index.html'로 해줘(그래야 주소가 깔끔하게 바로 열림).
- 깃허브에 로그인돼 있으면: 저장소(repo)를 새로 만들고 → 파일 올리고 → Pages 설정까지 '알아서' 한 뒤, 완성된 '내 명함 주소(URL)'만 알려줘.
- 로그인이 안 돼 있으면: 내가 먼저 뭘 해야 하는지(가입·로그인) 한 번에 알려줘.
확인올린 뒤 1~2분 기다렸다, 폰 브라우저에서 그 주소가 열리는지 먼저 확인. (절차는 변동 가능 → 강의 직전 확인)
STEP 5따라 입력 · Cowork/Claude Code
② '앱처럼' 설정 입히기 (1/2) ↵ 다음 장에 이어짐
입력 도구 · Cowork/Claude Code
이 디지털 명함(index.html)을 '폰 홈 화면에 추가하면 앱처럼' 열리게 만들어줘. (GitHub Pages·https에 올린 상태)
[원하는 것]
- 웹앱 설정(manifest) 추가: 앱 이름 '내 명함'(짧은 이름도), 테마색·배경색, display=standalone(주소창 없이 전체화면), 시작 주소.
- 앱 아이콘을 '직접 만들어' 넣어줘: 로고 없으면 이름 이니셜('정') 심볼로. 192·512 PNG + 아이폰용 180 아이콘.
- 아이폰(iOS)도 되게 'apple-touch-icon'과 apple 웹앱 메타(전체화면·상태바)도 함께. (iOS는 manifest를 잘 안 따름)
- 인터넷이 잠깐 끊겨도 기본 화면은 열리게 '아주 짧은' 서비스워커 1개(이 페이지·아이콘·manifest만 캐시). 그 이상 복잡하게는 X.
