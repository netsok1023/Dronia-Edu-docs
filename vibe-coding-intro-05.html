AI가,
읽고·정리하고·기록해 주는 비서로.

오늘 AI는 어려운 걸 읽어주고, 귀찮은 걸 정리해주고, 매일을 기록하게 해줍니다.
방법은 똑같습니다 — 요청하고, 확인하고, 다듬기.

01
PART 01 · 읽기

어려운 문서를,
5분에.

보험 약관·채용공고·관공서 안내문 — 미루던 문서를 AI에게 통째로 맡깁니다. 도구 = Claude(웹) 또는 Cowork.
STEP 1도입 · 공감
읽기 싫으시죠?
저도요.
보험 약관, 가전 설명서, 관공서 안내문 — 안 읽으면 손해 보는 것들이라 미루기도 어렵습니다. 오늘은 이걸 AI에게 통째로 맡깁니다.
주 대상 = 시니어(약관·안내문) · 구직자(채용공고) · 재직자(보고서·회의록).
🟢 이 시연은 '복사 → 붙여넣기 → 부탁'만으로 누구나 따라 할 수 있습니다.
수업 중 문서 받기

구글에 검색해서, 여기서 다운로드

1
law.go.kr

법령

국가법령정보센터 — 구글 "국가법령정보센터 주택임대차보호법"
2
fss.or.kr

보험 약관

금융감독원·보험사 공시실 — 구글 "실손의료보험 표준약관 PDF"
3
job.alio.go.kr

채용공고

잡알리오 — 관심 공고의 첨부 공고문(PDF) 다운로드
4
보너스 · 시니어

가전 사용설명서

삼성·LG 다운로드센터 — 구글 "삼성 ○○ 사용설명서 다운로드"
사이트 메뉴·경로는 바뀔 수 있어 강의 직전 1회 직접 확인. 개인정보가 든 문서는 피하고 공개 표준문서로.
STEP 2따라 입력 · Claude(웹)
쉽게 5줄로 요약
입력 도구 · Claude(웹)
아래 문서를 초등학생도 이해할 만큼 쉬운 말로 5줄로 요약해줘.
- 어려운 용어가 나오면 괄호로 짧게 풀어줘.
- 문서에 있는 내용만 — 추측하지 말고, 확실치 않은 건 '문서에 명확치 않음'으로 표시해줘.
[문서]
(여기에 약관·매뉴얼·공고 전체를 붙여넣기)
원칙확실치 않으면 '확인 필요'로 — 지어내지 않습니다.
STEP 3따라 입력 · Claude(웹)
궁금한 걸 다시 묻기
입력 도구 · Claude(웹)
· 위약금·해지 관련 내용만 표로 정리해줘 (조건 / 금액·비율 / 근거 조항).
· 나에게 불리할 수 있는 조항만 따로 모아 쉽게 설명해줘.
· 'O개월 안에 해지하면 어떻게 되는지'만 알려줘.
· (채용공고면) 자격요건·우대사항·마감일만 표로 뽑아줘.
리듬한 번에 끝낼 필요 없어요 — 궁금한 걸 계속 되물으면 점점 내게 맞는 답이 됩니다(바이브코딩의 리듬).
STEP 4따라 입력 · Claude(웹)
요약·표·용어·'내게 주는 의미'
입력 도구 · Claude(웹)
위 문서를 아래 형식으로 한 번에 정리해줘. (문서에 있는 사실만 · 추측 금지)
1) 한눈 요약 — 5줄, 쉬운 말로.
2) 핵심 비교표 — 항목 / 내용 / 근거(조항·페이지).
3) 모르는 용어 풀이 — 어려운 단어 5개를 한 줄씩.
4) '나에게 주는 의미' — 내가 챙겨야 할 점 3가지 + 확인 체크리스트(□).
확실치 않은 부분은 '원문·담당자 확인 필요'로 표시해줘.
완성같은 문서, 부탁 한 끗 차이 — 요약·표·용어풀이·체크리스트가 한 화면에.
STEP 5 닫기 · 꼭 기억할 것
!
AI는 '그럴듯하게' 틀릴 수 있습니다(환각).
돈·날짜·법률 조항처럼 중요한 숫자는 반드시 원문이나 담당자에게 다시 확인하세요. AI는 먼저 읽고 이해를 돕는 비서이지, 최종 책임자가 아닙니다.

AI는 만들기 전에, 먼저 '읽고 이해하는' 비서다.
02
PART 02 · 정리

폴더 정리를,
말로.

종류별·날짜별 정리 + 규칙적인 이름 — Claude Code로 내 컴퓨터에서 실제로 일을 시킵니다.
STEP 6 도입 · 공감
바탕화면에 '새 폴더'
있으신 분?
1
문제

뒤섞인 다운로드 폴더

사진 수백 장·영수증 스캔·정체불명 파일이 한데 쌓여 있습니다.

2
방법

말로 시켜서 정리

Claude Code에게 부탁하면 내 컴퓨터에서 실제로 실행합니다.

3
핵심

'일하는' AI = 에이전트

설명만 하는 챗봇과 달리 파일을 실제로 옮깁니다(2차시 증거).

(데모용) 파일이 뒤섞인 폴더를 화면에 띄우고 시작합니다.
STEP 7 안전이 먼저
✓
정리 전에 딱 하나 약속 — 원본은 절대 먼저 건드리지 않습니다.
'복사본'을 만들어 거기서 먼저 시험합니다(우리 사진자료 NAS도 '복사만' 하는 것과 같은 원칙). 그리고 Claude Code가 내 폴더에 접근해도 되는지 먼저 허락을 받습니다 — 이게 '웹'과 다른, 내 컴퓨터에서 실제로 일하는 AI라는 증거입니다.
STEP 8따라 입력 · Claude Code
종류별로 나누기
입력 도구 · Claude Code
이 폴더([폴더 경로])의 파일들을 종류별로 폴더를 만들어 정리해줘.
- 사진(jpg·png·heic) / 문서(pdf·docx·hwp·txt) / 압축(zip·rar) / 기타.
- ★ 원본을 지우지 말고, 먼저 이 폴더를 통째로 '복사본'으로 만든 뒤 '복사본'에서만 정리해줘.
- 무엇을 어디로 옮길지 먼저 목록으로 보여주고, 내가 확인하면 그때 옮겨줘.
빠진 정보 있으면 작업 전에 먼저 물어봐줘.
안전'먼저 목록 → 확인 → 실행' 순서 — 시키는 대로 바로 옮기지 않게 합니다.
STEP 9따라 입력 · Claude Code
날짜별 + 이름 규칙
입력 도구 · Claude Code
방금 정리한 '사진' 폴더를 더 정리해줘.
- 찍은 날짜 기준으로 'YYYY-MM' 폴더로 나눠줘.
- 파일 이름을 '2024-가족여행-01' 식(연도-주제-순번)으로 바꿔줘. 주제는 내가 불러줄게.
- 바꾸기 전후 목록을 표로 보여주고, 내가 확인하면 적용해줘.
체감외주 주거나 포기하던 일이, 말 몇 마디로 — 반나절 걸릴 노가다가 정리되어 끝납니다.
STEP 10 마무리

귀찮은 컴퓨터 일을, '말로' 시킨다

①
원칙
원본 보존, 복사본에서
삭제·이동은 늘 복사본에서 먼저 — 실수해도 원본은 그대로.
②
증거
챗봇 ≠ 에이전트
챗봇은 '이렇게 정리하세요' 설명만 하지만, 에이전트(Claude Code)는 실제로 정리해 줬습니다(2차시 '챗봇 vs 에이전트'의 증거).
말하는 AI를 넘어 — 내 책상에서 '실제로 일하는' AI.
03
PART 03 · 기록

혈압을,
매일 기록.

정리를 넘어 — 매일 쌓는 기록까지. Claude Code로 나만의 웹앱을 만듭니다.
STEP 11 도입 · 개념
수첩에 혈압 적다
빠뜨린 적 있죠?
오늘은 나만의 혈압 기록 앱을 직접 만듭니다. 단, 오해 하나 — 이건 앱스토어에서 받는 앱이 아니라, '한 페이지짜리 웹앱'입니다. 주소(또는 파일) 하나면 폰·PC에서 바로 열리고, 내 기록은 내 기기 안에만 저장됩니다.
앱스토어 앱 ❌ → 내 전용 '한 페이지 웹앱' ⭕ · 데이터는 내 기기에만
핵심 개념 3가지

설치 없이, 내 기기 안에서

1
웹앱

설치 없는 웹앱

주소나 파일 하나면 폰·PC 브라우저에서 바로 열립니다.

2
로컬 저장

데이터는 내 기기에만

localStorage에 저장 — 서버로 전송되지 않습니다.

3
홈 화면

폰 홈 화면에 추가

아이콘을 추가하면 앱처럼 열립니다.

이 세 가지가 오늘 만들 웹앱의 뼈대입니다.
STEP 12따라 입력 · Claude Code
기본 앱 만들기(입력+그래프)
입력 도구 · Claude Code
내 혈압을 매일 기록하는 '한 페이지 웹앱'을 만들어줘. (HTML 파일 하나, 설치 없이 브라우저에서 열림)
- 입력: 날짜, 수축기(높은 값), 이완기(낮은 값), 맥박, 메모.
- 기록을 목록과 '꺾은선 그래프'로 보여줘(수축기·이완기 함께).
- 데이터는 내 브라우저(localStorage)에만 저장 — 서버로 보내지 마.
- 휴대폰에서도 잘 보이게(모바일 우선), 글씨 크게.
다 만들면 어떻게 여는지 알려줘.
체감내 전용 기록 앱이 생겼습니다 — '오, 되네!'
STEP 13따라 입력 · Claude Code
실사용 기능 업그레이드
입력 도구 · Claude Code
방금 혈압 앱을 더 쓸모 있게 업그레이드해줘. (기존 디자인·저장 방식은 유지)
- 그래프에 '정상 범위 띠'(수축기 120·이완기 80 기준선)를 옅게 표시.
- 맨 위에 '최근 7일 평균' 카드.
- 각 기록을 수정·삭제.
- '내보내기(백업 파일 저장)'와 '불러오기'(기기 바꿔도 옮기게).
맥락의 힘'고칠 곳·유지할 것'을 분명히 말하면 한 번에 좋아집니다.
완성 · 내 혈압 기록 앱
화면 속 수치는 데모용 예시 데이터입니다(실제 기록 아님).
완성 데모 열기 · 혈압기록.html ↗
주의 · 꼭 확인
!
정상범위 숫자(120/80 등)는 예시입니다.
실제 기준은 의료진·공신력 있는 자료로 확인하세요 — 이 앱은 진단·처방이 아니라 '기록 도우미'입니다. 이상 수치는 꼭 의료진에게 확인하세요.
STEP 14따라 입력 · Claude Code
폰에 올려 쓰기(GitHub Pages)
입력 도구 · Claude Code
이 앱을 내 휴대폰에서도 쓰고 싶어. GitHub에 올려 'GitHub Pages'로 공개하고, 접속 주소를 알려줘.
(권한 요청하면 승인할게. 비공개로 두는 방법도 함께 알려줘.)
선택PC에서만 쓰긴 아깝습니다 — 폰에 올려 진짜로 써 봅니다.
폰에서 — 홈 화면에 추가

아이콘 탭 = 전체화면 명함처럼

1
아이폰 · 사파리

공유 → 홈 화면에 추가

  • Safari로 주소 열기 (크롬 말고 사파리)
  • 화면 하단 가운데 공유 아이콘 탭
  • 목록 내려 '홈 화면에 추가'
  • 오른쪽 위 '추가' 탭 → 완료
2
안드로이드 · 크롬

⋮ → 홈 화면에 추가

  • Chrome으로 주소 열기
  • 우측 상단 ⋮(메뉴) 탭
  • '홈 화면에 추가' (또는 '앱 설치')
  • '추가'/'설치' 탭 → 완료
GitHub Pages 주소는 보통 공개입니다 — 민감정보면 비공개 방법을 확인하세요. 파일은 https 주소로 여세요(file:// 더블클릭은 저장이 불안정).
STEP 15 마무리

내 일상을 기록·관리하는 도구까지

①
핵심
내 전용 도구를 말로
설치·개발 지식 없이 나만의 기록 앱을 만들었습니다.
②
핵심
데이터는 내 기기 안에만
그래서 백업(내보내기/불러오기)이 안전벨트입니다.
③
핵심
의료조언이 아니다
이상 수치는 꼭 의료진에게 확인 — 이 앱은 기록 도우미입니다.
같은 구조로 — 가계부(수입·지출·잔액)·운동·체중·독서 기록. 주제 단어만 바꾸면 됩니다.
