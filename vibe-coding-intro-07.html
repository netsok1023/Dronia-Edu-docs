오늘의 집(폴더) 하나부터 정한다.
예: 바탕화면에 두더지게임 폴더 하나. 오늘 만드는 HTML·이미지(images/)·소리가 전부 이 폴더에 모입니다.
파일은 '두더지잡기.html' 하나로 끝까지 키웁니다 — 새 파일을 만들지 않고 항상 "이어서" 부탁합니다.
Cowork는 폴더·파일명을 말해 주면 그 안에 저장하고, Claude Code는 그 폴더를 연 상태로 시작하면 자동으로 그 안에 생깁니다. 만든 뒤엔 어디에 저장됐는지 꼭 확인합니다.
01
PART 01 · 기초 만들기

게임판 → 등장 →
점수, 되네!

처음부터 거창하게 안 갑니다. 구멍판부터, 두더지 등장, 그다음 점수 — 딱 하나씩만 부탁합니다.
STEP 2따라 입력 · Cowork
게임판 만들기
입력 도구 · Cowork
'두더지 잡기' 게임을 HTML 파일 하나로 만들어줘(설치 없이 브라우저에서 열림).
- 화면 가운데에 구멍 9개(3×3 격자)와 제목 '두더지 잡기'.
- 모던하고 귀여운 느낌, 휴대폰에서도 잘 보이게(반응형).
- 아직 두더지·점수는 없어도 돼. 일단 게임판만.
- 파일은 바탕화면 '두더지게임' 폴더에 '두더지잡기.html'로 저장해줘.
다 만들면 어디에 저장됐는지(폴더 위치)와 어떻게 여는지 알려줘.
확인결과를 열기 전에 파일이 어디 있는지부터 확인 — 폴더를 못 찾으면 다음 단계가 다 막힙니다.
STEP 3따라 입력 · Cowork
두더지 등장
입력 도구 · Cowork
방금 만든 두더지 잡기에 이어서(새로 만들지 말고):
- 구멍 9개 중 무작위 한 곳에서 두더지가 '뿅' 나왔다 사라지게 해줘.
- 두더지는 이모지(예: 🐹)로 표시.
- 처음엔 천천히 — 두더지가 나오면 약 1.5초 머물다 사라지고, 한 박자 쉬었다 다음 두더지가 나오게(초보가 마우스로 쫓아갈 수 있게 넉넉히).
- 속도는 지금 올리지 마(점점 빨라지는 건 나중 단계에서 할 거야).
팁두더지가 너무 빨리 사라지면 초보는 못 잡습니다 — 처음엔 '느리고 오래 머물게'가 정답. 빨라지는 재미는 난이도 단계에서 줍니다.
STEP 4따라 입력 · Cowork
잡으면 점수
입력 도구 · Cowork
이어서:
- 두더지를 클릭(터치)하면 점수가 +1 되고 그 두더지는 바로 사라지게.
- 두더지가 있는 '구멍 칸 전체' 어디를 눌러도 잡히게 해줘 — 이모지(그림)의 일부만 인정되면 안 되고, 그 칸 영역이면 다 인정. 손가락·마우스가 조금 빗나가도 잡히게 넉넉히.
- 화면 위에 '점수: 0'을 크게 표시.
팁클릭 인정 범위(히트박스)가 좁으면 "분명 눌렀는데 안 잡혀!" 하고 답답해집니다 — "두더지 칸 전체를 눌러도 잡히게"라고 콕 집어 말하면 해결됩니다.
STEP 5
잠깐, 아쉬운 점
한참 하다 보면 —
'끝이 없네? 기록도 없고…' 〔아쉽네…〕
눌리고 점수가 오르는 손맛은 확인했습니다. 그런데 게임에 끝도, 기록도 없어 조금 심심합니다. 바로 그때가 다음 단계로 넘어갈 타이밍입니다.
PART 02 · 진짜 게임

타이머 · 결과 ·
최고기록, 와~!

시간과 기록이 붙는 순간, 눌러보는 장난감이 '진짜 게임'이 됩니다 — 오늘의 전환점입니다.
STEP 6따라 입력 · Cowork
타이머 + 결과 + 최고기록
입력 도구 · Cowork
이어서, 진짜 게임처럼 만들어줘:
- '시작' 버튼을 누르면 30초 카운트다운 시작, 0이 되면 끝.
- 끝나면 '점수 ○점!' 결과 화면 + '다시 하기' 버튼.
- 최고 점수를 기억해서 보여줘(내 브라우저에만 저장).
전환점시작 → 30초 → 결과 → 최고기록. 시간·점수·기록이 갖춰지며 비로소 '게임'이 됩니다.

PART 03 · 완성도 높이기

효과 · 방식 ·
난이도

한 번에 다 말고 하나씩 — 그리고 이미 만든 게임도 말 한마디로 규칙이 바뀝니다. 우리가 곧 디자이너입니다.
STEP 7따라 입력 · Cowork
① 잡는 손맛(효과)
입력 도구 · Cowork
이어서, 두더지를 잡으면 '퍽' 하는 느낌(살짝 커졌다 사라지거나 색 변화)과 점수가 톡 튀게 해줘. 휴대폰 터치로도 잘 잡히게.
감각짧고 산뜻한 반응 하나가 게임의 '손맛'을 결정합니다.
규칙을 바꿔보는 경험
이미 만든 게임도
말 한마디로 규칙이 바뀐다.
지금은 '30초 동안 많이'였습니다. 여기에 '두더지 30마리 중 몇 마리' 방식을 더하면, 똑같은 게임인데 규칙만 바꿔 완전히 다른 재미(속도 대결 ↔ 정확도 대결)가 나옵니다. 우리가 곧 디자이너입니다.
STEP 7따라 입력 · Cowork
② 게임 방식 바꾸기(시간제 ↔ 마릿수제)
입력 도구 · Cowork
지금 두더지 잡기에 '게임 방식 선택'을 추가해줘. (기존 시간제 30초는 그대로, 방식만 하나 더)
- 시작 화면에서 둘 중 고르기:
  (1) 시간제 — 30초 동안 많이 잡기 (지금 방식)
  (2) 마릿수제 — 두더지가 차례로 30마리 나오고, 그중 몇 마리 잡았는지 겨루기
- 마릿수제일 때: 화면에 '남은 두더지 ○/30' 표시, 30마리가 다 지나가면 끝.
- 결과 화면: '30마리 중 ○마리 명중 (명중률 ○○%)' 표시.
- 최고기록은 방식별로 따로 기억.
[하지 말 것] 기존 점수·효과·디자인 깨지 말 것, 단일 HTML·반응형 유지.
[★ 타이머 주의] 카운트다운 타이머는 '항상 하나만' 돌게 해줘 — 새로 시작하기 전에 이전 타이머를 반드시 정리(clearInterval)하고 시작. 마릿수제일 때는 30초 카운트다운이 돌지 않게.
STEP 7따라 입력 · Cowork
③ 난이도 선택(쉬움 · 보통 · 어려움)
입력 도구 · Cowork
이어서 '난이도 선택(쉬움 / 보통 / 어려움)'을 추가해줘.
- 난이도에 따라 두더지가 '머무는 시간'과 '나오는 간격'이 달라지게(쉬움=느긋, 어려움=빠름).
- 마릿수제면 마릿수도 난이도로(예: 쉬움 15 / 보통 30 / 어려움 30+빠름). 너무 어렵진 않게.
- 고른 난이도는 기억(localStorage).
[하지 말 것] 단일 HTML·반응형 유지, 기존 로직 깨지 말 것.
[★ 타이머 주의] 난이도를 바꿔 다시 시작할 때도 이전 카운트다운 타이머를 정리하고, 타이머는 하나만 돌게.
(선택) 원하면 한 판 안에서도 시간이 갈수록 두더지가 조금씩 더 빨리 나오게 할 수도 있어 — 너무 어렵지 않게.
개념난이도란 결국 '숫자(속도·시간·마릿수)를 바꾸는 것' — 이 감을 잡는 단계입니다.
자주 나는 버그 · 강의 직전 알아두기
⏱
시간이 너무 빨리 줄어요?
카운트다운이 2~3배로 마구 줄어들면(다시 시작할수록 더 빨라지면) = 타이머가 여러 개 겹쳐서 도는 것입니다. 시작할 때마다 이전 타이머를 끄지 않고 또 켜서 생깁니다.

해결 한마디 — "카운트다운 타이머는 항상 하나만 돌게, 시작 전에 이전 타이머를 정리해줘." 앞의 ②③ 프롬프트의 〔★ 타이머 주의〕가 애초에 이 버그를 막아 줍니다. 입문 단골 버그라 미리 알면 당황하지 않습니다.

PART 04 · 내 캐릭터로

라이선스 안전하게,
자랑할 캐릭터로

두더지를 내 캐릭터로 바꿉니다. 단, 인터넷 이미지를 아무거나 쓰면 안 됩니다(저작권) — 합법 무료 출처만 씁니다.
STEP 8따라 입력 · Cowork · 가장 쉬움
① 이모지 바꾸기(다운로드 0)
입력 도구 · Cowork
이어서, 두더지 이모지를 다른 걸로 바꿔줘(예: 🦔 또는 내가 고른 이모지).
가장 쉬움이모지는 시스템 글자라 라이선스 걱정이 0입니다.
방법 1 · 직접 사이트에서 골라 받기(추천)
합법 무료 사이트 → 다운로드 → images/에 저장
합법 무료 사이트에 접속해 마음에 드는 캐릭터(투명 PNG)를 다운로드하고, 작업 폴더의 images/에 저장합니다. OpenMoji(openmoji.org — 검색 후 Download PNG, CC BY-SA로 출처 표기) · 대안으로 Pixabay·Pexels의 무료 사진.
연결 프롬프트 · Cowork
이어서, 두더지 자리에 'images/내가받은_캐릭터.png'를 캐릭터로 써줘. (출처·라이선스는 페이지 아래에 표기)
주의사이트 메뉴·다운로드 버튼 위치는 바뀔 수 있어 강의 직전 1회 확인. 라이선스 불확실하면 쓰지 않습니다.
방법 2 · AI가 대신 받아오기
Cowork · Claude Code에 통째로 부탁
입력 도구 · Cowork · Claude Code
재사용이 허용된 무료 출처(예: OpenMoji)에서 게임 캐릭터 이미지를 받아 같은 폴더 images/에 저장하고 두더지 자리에 써줘.
출처·라이선스를 페이지에 표기하고, 라이선스가 불확실하면 쓰지 말고 알려줘(그땐 이모지 유지).
참고AI가 알아서 받아오지만 라이선스 안전 이미지를 자동으로 못 구할 수 있음 — 그땐 방법 1(직접) 또는 이모지 유지. 원하면 내 얼굴·직접 그린 그림도 캐릭터로 넣을 수 있습니다.

입력 도구 · Cowork
배경음(BGM)을 게임답게 바꿔줘. (효과음·게임 로직은 그대로)
- 플레이가 시작되면 신나는 BGM이 흐르고, 게임이 끝나면(게임오버) BGM이 멈춰 조용해지게.
- 한 음 반복 말고 '짧고 경쾌한 리듬+멜로디 루프'(4~8초)로 자연스럽게 반복.
- 타이틀 화면에서는 조용히(또는 아주 잔잔하게).
- (중간 재미) 남은 시간이 얼마 안 남으면 살짝 빨라지거나 긴박해지게.
[방식] 파일 없이 Web Audio로 코드 합성, 🔊 켜기/끄기 토글·음소거 기억(localStorage)은 유지.
[하지 말 것] 거슬리지 않게(볼륨·고음 과하지 않게), 모바일은 첫 터치 후 소리, 단일 HTML 유지, 타이머는 하나만(겹침 금지).
교육포인트브라우저는 사용자가 한 번 누른 뒤에야 소리를 허용 — '시작' 버튼에서 오디오를 켭니다. BGM은 '한 음 반복'이면 지루하니 짧은 멜로디 루프로, 시작/종료에 맞춰 켜고 끄면 단숨에 게임다워집니다.
B. 타이틀 · 카운트다운 · 게임오버 화면 🎬
지금은 페이지를 열면 곧바로 게임이 돕니다. 진짜 게임은 '타이틀 → 3·2·1 → 플레이 → 게임오버 → 다시' 흐름이 있습니다 — 이 화면 흐름만 붙여도 완성품 느낌이 확 납니다.
입력 도구 · Cowork
[입력] 게임에 '제대로 된 3개 화면'을 만들어줘. (기존 플레이 로직 유지)
1) 타이틀 — 큰 제목 '두더지 잡기' + 최고 점수 + '시작' 버튼(+간단한 방법 한 줄)
2) 카운트다운 — 시작을 누르면 3·2·1 큰 숫자가 사라지며 곧바로 시작
3) 게임오버 — '점수 ○점', 신기록이면 '신기록!' 강조, '다시 하기'/'타이틀로'
[전환] 화면 사이를 부드럽게(페이드), 한 화면만 보이고 나머진 숨김.
[★ 타이머 주의] 화면을 바꿀 때마다 이전 카운트다운·BGM·두더지 등장 타이머를 모두 정리(clearInterval)하고, 타이머는 항상 하나만 돌게.
[하지 말 것] 단일 HTML·반응형 유지, 기존 점수·타이머 로직을 깨지 말 것.
교육포인트게임은 상태(타이틀/플레이/종료)를 나눠 관리하면 화면 전환이 깔끔합니다 — '상태' 개념을 자연스럽게 체감합니다.
C. 두더지 종류 + 생명 🐹💣
지금은 두더지가 다 똑같습니다. 황금 두더지(대박)와 폭탄(함정), 거기에 하트 생명까지 넣으면 — '막 누르면 안 되고 골라서 빠르게' 쳐야 하는 긴장감이 생겨 게임이 단숨에 깊어집니다.
입력 도구 · Cowork
[입력] 두더지에 '변화와 긴장'을 넣어줘. (기존 점수·타이머 유지)
[종류] 일반(잡으면 +1) / 황금(가끔·약 10%, +5, 더 빨리 사라짐) / 폭탄(가끔, 누르면 -1점·생명 -1 — 잡으면 안 됨)
[생명] 하트 3개. 폭탄을 누르거나 일반·황금을 '시간 내 못 잡으면' 생명 -1, 0이면 즉시 게임오버.
[표시] 위쪽에 점수·남은 시간·하트를 한눈에. 종류는 모양으로도 구분(색만으로 구분 금지).
[하지 말 것] 너무 어렵지 않게(폭탄 비율 과하지 않게), 단일 HTML·반응형 유지.
교육포인트'변수(황금·폭탄)'와 '리스크(생명)'를 넣으면 게임이 단숨에 깊어집니다 — 좋은 게임 디자인의 핵심입니다.
D. 콤보 + 파티클(손맛) ✨
같은 게임도 '손맛'에서 갈립니다. 연속으로 빠르게 잡으면 점수가 배로(콤보), 잡는 순간 점수가 톡 튀고 별이 흩어지면 손이 근질근질해집니다 — 사람들이 게임을 계속하게 만드는 '피드백'입니다.
입력 도구 · Cowork
[입력] '잡는 손맛'을 키워줘. (기존 로직 유지)
[콤보] 일반·황금 두더지를 연속으로 잡으면 콤보가 쌓이고 점수 배수(x2·x3). 'COMBO x3!'를 잠깐 크게.
[콤보 끊김] 콤보는 딱 두 경우에만 초기화 — ①폭탄을 '눌렀을 때' ②잡을 수 있는 두더지를 '시간 안에 못 잡고 놓쳤을 때'. 폭탄이 '나오기만' 하거나 '안 누르고 피한' 것은 콤보 유지(폭탄만 떠 있는 시간은 세지 말 것).
[타격 효과] 잡는 순간 얻은 점수(+1/+5)가 그 자리에서 톡 튀어오르며 사라지고, 작은 별·빛이 살짝 흩어지게.
[하지 말 것] 외부 라이브러리 없이 가볍게(과한 애니메이션·성능 저하 금지), 효과는 짧고 산뜻하게, 단일 HTML 유지.
★ 실측 보완'피드백(콤보·파티클)'이 재미의 8할 — 단, 과하면 어지러우니 절제. 규칙의 '끊김 조건'을 분명히 해야 '폭탄 잘 피했는데 억울하게 콤보 깨짐' 같은 일이 안 생깁니다.
E. 로컬 랭킹 + 자랑하기 🏆
게임의 끝은 결국 '자랑'입니다. Top 5 명예의 전당을 두면 '한 판 더!'가 되고, 결과를 예쁜 카드 이미지로 만들어 공유하면 친구에게 도전장을 던질 수 있습니다. 단, 점수는 내 폰 안에만 저장(서버·로그인 없음).
입력 도구 · Cowork
[입력] '경쟁'과 '자랑'을 넣어줘. (점수는 내 브라우저에만 저장·서버 없음)
[랭킹] 게임오버 때 점수가 Top 5 안에 들면 닉네임을 입력받아 저장, 타이틀/게임오버에 'Top 5 명예의 전당' 표시(localStorage).
[자랑하기] 결과 화면에 '자랑하기' 버튼 — 점수·날짜·게임 제목이 담긴 예쁜 '결과 카드'를 만들어 저장/공유.
  - 카드는 화면 캡처가 아니라 코드로 그려서(canvas) PNG 이미지로 생성.
  - ★저장 방식은 기기에 맞게:
     · PC(데스크톱) = '공유창' 말고 바로 파일로 저장(다운로드 폴더)
     · 휴대폰 = 공유 시트(사진 앱 저장·카톡 전송 등)
  - 저장이 끝나면 화면에 '저장했어요 — 다운로드 폴더 확인' 같은 안내를 잠깐 띄워줘.
  - 문구 예: "두더지 잡기 ○점! 도전해봐 🐭".
[하지 말 것] 외부 서버·로그인·개인정보 X, 단일 HTML 유지.
  이미지 저장이 PC·폰 둘 다 '실제로' 되게 — 특히 윈도우 '공유'창엔 폴더 저장이 없으니 PC는 반드시 다운로드 방식으로.
★ 실측 보완'이미지로 저장/공유'는 화면을 그림으로 굽는 기술(canvas) — 저장은 기기마다 다릅니다: PC는 '공유창'에 폴더 저장이 없어 바로 다운로드해야 하고, 폰은 공유 시트가 자연스럽습니다.
F. 배경 테마 3종 🎨
내용은 그대로 둔 채 배경만 잔디밭·사막·우주로 바꿔 주면 완전히 새 게임처럼 보입니다 — '스킨'의 힘입니다. 단, 어떤 테마에서도 글자·두더지가 잘 보이게(대비)가 원칙입니다.
입력 도구 · Cowork
[입력] '분위기 전환'을 넣어줘. (가독성·게임성 유지)
[테마] 잔디밭/사막/우주 3종 — 배경·구멍 모양·강조색이 테마별로 바뀌게, 버튼으로 즉시 전환, 선택 기억(localStorage).
[하지 말 것] 어떤 테마에서도 점수·두더지·글자가 잘 보이게(대비 유지), 사진을 쓰면 CC0만, 단일 HTML·반응형 유지.
교육포인트같은 게임도 '스킨'만 바꾸면 새 느낌 — 색·대비는 가독성 우선(접근성)입니다.
